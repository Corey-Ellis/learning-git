# Git Basics

## Repository
My definition: A project and a history of the changes made.

## Clone
My definition: A local copy made of a project that is online.

## Branch
My definition: An "offshoot" where changes can be made without potentially ruining the main project.

## Stage
My definition: After changes are saved and can be examined before commited.

## Commit
My definition: A meaningful snapshot of the changes made.

## Push
My definition: Sending changes you made to a project online.

## Pull
My definition: Pulling info from a project.  If changes were made, you are updating your local copy.

## Merge
My definition: After a pull request, if the commit is approved, it is merged with the main project.

## Pull Request
My definition: Requesting a review of a commit before it is made permanant.
