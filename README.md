# learning-git

This repository documents my practice while learning Git and GitHub.

## Goals

- Learn how repositories work
- Understand commits
- Practice pushing and pulling changes
- Learn branches
- Practice pull requests

## What Iv'e Learned

### Git
Git is a program that tracks changes to a project.

### GitHub
GitHub is like the "social media" for Git.  It hosts the repositories so that others can not only see them, but they can collabrate and evaluate them as well.

### Commit
A commit is a meaningful snapshot of the changes that were done to a repository.
